Add a `combobox-*` set for Combobox. The popup, row, group, separator, search, loading and empty tokens copy the `dropdown-*` values, so the popup matches Dropdown. The chip tokens copy `pill-rect-solid-*`. The field uses `l2-border` (`l3-border` on hover), `l1-foreground` for the value, `l3-foreground` for the placeholder and icons, and `primary-background` for the focus ring.
