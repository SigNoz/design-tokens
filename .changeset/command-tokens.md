Add a `command-*` set for the Command palette. The values copy the popup part of the `combobox-*` set, so the palette matches Dropdown, Combobox and Select. There are no trigger, chip, control or separator tokens, since the palette has none of them. `command-backdrop` dims the page behind the palette, with the overlay colour of `Dialog`.
